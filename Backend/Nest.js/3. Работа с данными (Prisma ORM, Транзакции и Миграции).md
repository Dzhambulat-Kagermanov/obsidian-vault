**Цель:** Эффективная и безопасная работа с реляционными базами данных (PostgreSQL). **Что записать:**

- **Почему Prisma:** Типобезопасность из коробки, отличная поддержка TypeScript, удобные миграции. (Краткое упоминание TypeORM как legacy-варианта).
- **Интеграция с NestJS:** Создание `PrismaService` расширяющего `PrismaClient`, реализующего `onModuleInit` и `onModuleDestroy` для корректного закрытия соединений.
- **Транзакции:** Интерактивные транзакции (`prisma.$transaction([ ... ])`) для обеспечения атомарности операций (например, создание заказа и списание баланса).
- **N+1 проблема:** Как избегать её в Prisma (использование `include` или раздельных запросов с последующим маппингом в памяти).
- **Миграции:** `prisma migrate dev` vs `prisma migrate deploy` в CI/CD.
