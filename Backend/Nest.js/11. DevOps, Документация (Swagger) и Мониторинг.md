**Цель:** Подготовка приложения к жизни в production-среде. **Что записать:**

- **Swagger (OpenAPI):** Модуль `@nestjs/swagger`. Декораторы `@ApiTags`, `@ApiOperation`, `@ApiResponse` для автоматической генерации интерактивной документации.
- **Конфигурация:** Использование `@nestjs/config` и `zod` (или `class-validator`) для валидации `.env` переменных при старте приложения (Fail Fast принцип).
- **Логирование и Мониторинг:** Замена стандартного логгера на `pino` (`nestjs-pino`) для структурированных JSON-логов. Интеграция с OpenTelemetry для трейсинга запросов и Sentry для отслеживания ошибок.
- **Docker:** Написание эффективного `Dockerfile` (multi-stage build, использование `node:alpine`, запуск от имени non-root пользователя, использование `pm2` или `dumb-init` для управления процессами).
