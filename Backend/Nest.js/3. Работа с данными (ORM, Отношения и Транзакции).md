**Цель:** Правильная работа со связанными данными, избегая N+1 и ошибок целостности. **Что записать:**

- **Синтаксис отношений в Prisma:**
    - One-to-One (`user Profile? @relation(fields: [userId], references: [id])`)
    - One-to-Many (`posts Post[]` и обратная связь `author User @relation(...)`)
    - Many-to-Many (Implicit `users User[]` vs Explicit через связующую таблицу `UserOnProject`).
- **Nested Writes (Вложенные записи):** Как создать пользователя и его профиль/посты _одной_ командой:
```ts
prisma.user.create({ data: { email: '...', profile: { create: { bio: '...' } } } })
```
- **Проблема N+1:** Почему `include: { posts: true }` внутри цикла — это зло. Решения: использование `$transaction` для пакетной загрузки или раздельные запросы с маппингом в памяти (`Map` или `Object.groupBy`).
- **Транзакции:** Интерактивные (`await prisma.$transaction([ ... ])`) и изолированные (для сложных бизнес-процессов).
