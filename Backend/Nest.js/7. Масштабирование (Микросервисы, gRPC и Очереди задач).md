**Цель:** Выход за рамки монолита при росте нагрузки. **Что записать:**

- **Микросервисы:** Транспортные слои (`@nestjs/microservices`): TCP, Redis, RabbitMQ, Kafka, gRPC. Почему gRPC предпочтительнее для internal service-to-service communication (бинарный протокол, строгие контракты через `.proto`).
- **Очереди задач (Background Jobs):** Интеграция `@nestjs/bull` (BullMQ + Redis). Паттерны: отложенные задачи, повторные попытки (retry), обработка очередей воркерами.
- **Message Queues vs Event Bus:** Когда использовать надежную доставку через RabbitMQ, а когда достаточно in-memory событий.
