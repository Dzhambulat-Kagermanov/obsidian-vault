**Цель:** Покрытие кода надежными тестами, которые не ломаются при рефакторинге. **Что записать:**

- **Unit-тесты:** Тестирование изолированных сервисов с помощью `Test.createTestingModule`. Мокинг зависимостей через `useValue` или библиотеки типа `jest-mock-extended`.
- **Integration-тесты:** Тестирование взаимодействия сервиса с реальной (или тестовой) базой данных (использование `testcontainers` или in-memory БД, например, `sqlite` для тестов).
- **E2E-тесты:** Использование `supertest` для отправки реальных HTTP-запросов к запущенному приложению NestJS. Проверка статус-кодов, структуры ответа и побочных эффектов в БД.
- **Покрытие:** Настройка Jest для генерации отчетов о покрытии (`coverage`), игнорирование DTO и модулей в отчетах.
