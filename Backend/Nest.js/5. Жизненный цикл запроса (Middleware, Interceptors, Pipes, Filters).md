**Цель:** Полный контроль над тем, что происходит с запросом от момента получения до отправки ответа. **Что записать:**

- **Порядок выполнения:** Middleware → Guards → Interceptors (Pre) → Pipes → Controller → Interceptors (Post) → Exception Filters.
- **Exception Filters:** Глобальный фильтр ошибок (`@Catch()`) для перехвата всех исключений, логирования и возврата стандартизированного JSON-ответа (вместо стандартного HTML-стека NestJS).
- **Interceptors:** Преобразование ответа (например, обертка `{ data: ..., meta: ... }`), логирование времени выполнения запроса, кэширование ответов.
- **Pipes:** Не только для валидации, но и для трансформации данных (например, `ParseIntPipe`, `ParseUUIDPipe`).
