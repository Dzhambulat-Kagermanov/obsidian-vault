
Работа внутри области иерархически построена между маршрутизаторами, которые классифицируются следующим образом:

**Пограничный маршрутизатор области (Area Border Router, ABR)**. Маршрутизаторы, расположенные на границах каждой области, соединяющиеся с более чем одной областью OSPF, из которых одна является областью 0, называются ABR‑маршрутизаторами. Маршрутизаторы ABR отвечают за суммирование IP‑адресов каждой области;
* **Где находится:** На стыке Area 0 (Backbone) и любой другой области (Area 1, Area 2 и т.д.);
- **Главная задача:** Изолировать топологию одной области от другой, передавая только сводную информацию. Он не передает детали топологии (какие именно линки есть внутри Area 1) в Area 0, а вместо этого генерирует **LSA Type 3 (Summary LSA)**;
- **Требование к конфигурации:** У него **обязательно** должен быть хотя бы один интерфейс в Area 0 и хотя бы один в другой области.

**Маршрутизатор границы автономной системы (Autonomous System Boundary Router, ASBR)**. ASBR — это маршрутизатор, который имеет интерфейсы, подключенные к одной или нескольким областям OSPF, аналогично ABR, однако отличие ASBR в том, что это маршрутизаторы, являющиеся шлюзами между протоколом OSPF и любым другим протоколом динамической маршрутизации, таким как BGP, EIGRP, Статические маршруты, RIP и даже другой экземпляр OSPF на том же маршрутизаторе. Маршрутизатор ASBR обычно рассылают маршруты из других систем маршрутизации в область OSPF, к которой он принадлежит.
* **Главная задача:** "Впрыскивать" внешние маршруты в OSPF. Он генерирует **LSA Type 5 (External LSA)** (или Type 7 в NSSA областях).
* **Требование к конфигурации:** Наличие команды **redistribution**. Без явной редистрибьюции роутер не станет ASBR, даже если у него настроен например BGP.

**Назначенный маршрутизатор (Designated Router, DR)**. DR выбирается маршрутизаторами в сегментах множественного доступа (например, в локальной сети) на основе его приоритета (Router ID, приоритет). 
* Маршрутизатор DR выполняет специальные функции, такие как генерация объявлений о состоянии соединения (LSA) и обмен информацией со всеми другими маршрутизаторами в той же области. 
* Каждый маршрутизатор в той же области создает соседство с DR и BDR. Для каждой области выбирается только один DR и BDR с которого будут отправляться hello пакеты на все маршрутизаторы этой области.
- Между собой роутеры, которые не являются DR и BDR остаются в состоянии **2-WAY (TWO-WAY)** (они видят друг друга в Hello-пакетах, знают, что они существуют, но **не обмениваются базами данных**).
- DR отправляет обновления всем маршрутизаторам области, используя мультикастовый адрес 224.0.0.5. Все маршрутизаторы OSPF, кроме DR, используют мультикастовый адрес 224.0.0.6 для отправки пакетов Link State Update (LSU) и Link State Advertisements (LSAs) на DR. **Что происходит при изменении маршрутов:**
	1. Роутер X видит изменение. Он отправляет обновление **только** на мультикаст адрес `224.0.0.6` (AllDRouters).
	2. Только DR (и BDR) слушает этот адрес. DR принимает обновление.
	3. DR рассылает обновление всем остальным на адрес `224.0.0.5` (AllSPFRouters).

**Резервный назначенный маршрутизатор (BDR)**. BDR — это маршрутизатор, который становится DR в случае отказа существующего DR. BDR имеет второй по значению приоритет (DR имеет наивысший приоритет) в сети OSPF. Когда BDR становится DR, проводятся новые выборы для поиска нового BDR.

**Внутренний маршрутизатор (Internal router, IR).** - маршрутизатор, который всеми интерфейсами находится внутри одной области OSPF.
