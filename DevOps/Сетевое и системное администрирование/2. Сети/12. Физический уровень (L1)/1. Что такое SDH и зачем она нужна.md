| Вопрос                            | Ответ                                                                                                                                                                          |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Что такое SDH?**                | Синхронная цифровая иерархия — технология для передачи данных по оптическому волокну с гарантированной скоростью и высоким уровнем отказоустойчивости.                         |
| **Какие задачи решает?**          | 1) Объединяет множество каналов в один высокоскоростной поток. 2) Обеспечивает автоматическое восстановление при авариях (<50 мс). 3) Даёт единую синхронизацию для всей сети. |
| **В чём отличие от PDH?**         | В PDH каждый мультиплексор работал по своим часам. В SDH — единый источник синхронизации, что позволяет обращаться к любому каналу напрямую, не разбирая весь поток.           |
| **Почему SDH актуальна сегодня?** | Высокая надёжность (SLA 99,999%), гарантированная полоса, механизмы резервирования, поддержка Ethernet через GFP.                                                              |
