| Уровень                      | Название               | Что это                                                | Аналогия                          |
| ---------------------------- | ---------------------- | ------------------------------------------------------ | --------------------------------- |
| **Клиентский сигнал**        | E1, E3, Ethernet       | Данные клиента (2, 34, 100, 1000 Мбит/с)               | Письмо                            |
| **Контейнер**                | C (C-12, C-3, C-4)     | Первая упаковка клиентских данных                      | Картонная коробка                 |
| **Виртуальный контейнер**    | VC (VC-12, VC-3, VC-4) | C + адрес получателя                                   | Коробка с наклейкой               |
| **Административная единица** | AU                     | VC + указатель (где внутри кадра начало)               | Коробка с биркой «место в вагоне» |
| **Синхронный модуль**        | STM (STM-1,4,16,64)    | Готовый кадр для отправки в кабель                     | Железнодорожный вагон             |
| **Физический уровень**       | Оптическое волокно     | Лазер мигает (1 — мощнее, 0 — слабее, но всегда горит) | Рельсы                            |

**Главный принцип:** Всё вложено друг в друга (матрешка). Каждый уровень добавляет служебную информацию.
