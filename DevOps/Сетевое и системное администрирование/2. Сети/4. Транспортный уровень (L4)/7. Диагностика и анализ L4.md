|   |   |   +---Инструменты анализа
|   |   |   |       tcpdump: захват TCP/UDP трафика, фильтры (`tcp`, `udp`, `port`, `host`).
|   |   |   |       Wireshark: детальный анализ пакетов, follow TCP stream, статистика.
|   |   |   |       tshark: CLI-версия Wireshark для автоматизации.
|   |   |   |       ss (socket statistics): замена netstat, анализ сокетов и соединений.
|   |   |   |       netstat: устаревший, но все еще используется.
|   |   |   |       conntrack: анализ conntrack table (stateful firewall).
|   |   |   |       strace: трассировка системных вызовов (socket API).
|   |   |   |
|   |   |   +---Анализ TCP-соединений
|   |   |   |       Handshake analysis: проверка three-way handshake, задержки.
|   |   |   |       Retransmissions: анализ повторных отправок, причины (потери, таймауты).
|   |   |   |       Window size: анализ окна, zero window ситуации.
|   |   |   |       RTT (Round Trip Time): измерение задержки, вариации.
|   |   |   |       Throughput: расчет пропускной способности.
|   |   |   |       State transitions: анализ переходов между состояниями (ESTABLISHED, FIN_WAIT, TIME_WAIT).
|   |   |   |
|   |   |   +---Анализ UDP-трафика
|   |   |   |       Потеря пакетов: подсчет потерянных дейтаграмм.
|   |   |   |       Дубликаты: обнаружение дублирующихся пакетов.
|   |   |   |       Fragmentation: анализ фрагментированных UDP-дейтаграмм.
|   |   |   |       Multicast/Broadcast: анализ групповых и широковещательных сообщений.
|   |   |   |
|   |   |   \---Performance testing
|   |   |           iperf3: тестирование пропускной способности TCP/UDP.
|   |   |           netperf: более продвинутое тестирование производительности.
|   |   |           ping и traceroute: базовая проверка связности и задержек.
|   |   |           mtr: комбинация ping и traceroute с статистикой.
