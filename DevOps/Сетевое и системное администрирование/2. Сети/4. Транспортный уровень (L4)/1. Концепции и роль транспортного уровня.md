|   |   |       Место L4 в стеке OSI и TCP/IP: между сетевым (L3) и сессионным/представления/приложения (L5-L7).
|   |   |       Основные функции: сегментация данных, мультиплексирование (порты), контроль доставки.
|   |   |       Модель обслуживания: connection-oriented (TCP) vs connectionless (UDP).
|   |   |       Гарантии доставки: надежная (reliable) vs ненадежная (unreliable) доставка.
|   |   |       Контроль потока (flow control) и контроль перегрузок (congestion control): базовые концепции.
|   |   |       Инкапсуляция: сегменты (TCP) и дейтаграммы (UDP), заголовки L4.
|   |   |       Взаимодействие с L3: IP-протоколы (6 = TCP, 17 = UDP, 132 = SCTP).
|   |   |       Взаимодействие с L5-L7: сокеты (sockets), API (Berkeley Sockets).
