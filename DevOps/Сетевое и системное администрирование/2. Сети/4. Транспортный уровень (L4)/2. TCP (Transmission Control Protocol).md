+---Архитектура и заголовок TCP
|   |   |   |       Структура заголовка TCP: source port, destination port, sequence number, acknowledgment number.
|   |   |   |       Флаги: SYN, ACK, FIN, RST, PSH, URG, CWR, ECE.
|   |   |   |       Окно (window size): механизм скользящего окна.
|   |   |   |       Контрольная сумма (checksum): расчет и проверка.
|   |   |   |       Urgent pointer: устаревший механизм приоритетных данных.
|   |   |   |       Options: MSS (Maximum Segment Size), Window Scale, SACK (Selective Acknowledgment), Timestamps.
|   |   |   |
|   |   |   +---Установка и завершение соединения
|   |   |   |       Three-way handshake: SYN → SYN-ACK → ACK.
|   |   |   |       Последовательности номеров: initial sequence number (ISN), относительные номера.
|   |   |   |       Four-way handshake для завершения: FIN → ACK → FIN → ACK.
|   |   |   |       TIME_WAIT состояние: зачем нужно, длительность (2 * MSL), проблемы с портами.
|   |   |   |       TCP Fast Open (TFO): ускорение установки соединения.
|   |   |   |       Simultaneous Open: одновременное открытие соединения.
|   |   |   |
|   |   |   +---Надежная доставка данных
|   |   |   |       Sequence numbers и acknowledgment: как работает подтверждение.
|   |   |   |       Retransmission: повторная отправка потерянных сегментов.
|   |   |   |       Timeout и RTO (Retransmission Timeout): расчет, Karn's algorithm, Jacobson's algorithm.
|   |   |   |       Fast Retransmit: повторная отправка при получении 3 дубликатных ACK.
|   |   |   |       SACK (Selective Acknowledgment): подтверждение конкретных сегментов.
|   |   |   |       Duplicate ACK: что это, как обрабатывается.
|   |   |   |
|   |   |   +---Контроль потока (Flow Control)
|   |   |   |       Скользящее окно (sliding window): концепция, размер окна.
|   |   |   |       Window size advertisement: как получатель сообщает о доступном буфере.
|   |   |   |       Zero Window: ситуация, когда приемник не может принимать данные.
|   |   |   |       Window Scale option: поддержка больших окон (RFC 1323).
|   |   |   |       Nagle's algorithm: оптимизация отправки мелких пакетов.
|   |   |   |       Delayed ACK: задержка подтверждения для уменьшения трафика.
|   |   |   |
|   |   |   +---Контроль перегрузок (Congestion Control)
|   |   |   |       Концепция: предотвращение перегрузки сети.
|   |   |   |       Congestion Window (cwnd): динамическое окно перегрузки.
|   |   |   |       Slow Start: экспоненциальный рост cwnd.
|   |   |   |       Congestion Avoidance: линейный рост после достижения ssthresh.
|   |   |   |       Fast Recovery: восстановление после потери сегмента.
|   |   |   |       Алгоритмы: Reno, Tahoe, NewReno, CUBIC (стандарт для Linux), BBR (Google).
|   |   |   |       ECN (Explicit Congestion Notification): явное уведомление о перегрузке.
|   |   |   |
|   |   |   +---Оптимизации и расширения TCP
|   |   |   |       TCP Offload Engine (TOE): разгрузка TCP-стека на сетевую карту.
|   |   |   |       Large Segment Offload (LSO) / TCP Segmentation Offload (TSO).
|   |   |   |       Generic Segmentation Offload (GSO) / Generic Receive Offload (GRO).
|   |   |   |       TCP Multipath (MPTCP): использование нескольких интерфейсов/путей.
|   |   |   |       QUIC (UDP-based): альтернатива TCP от Google, основа HTTP/3.
|   |   |   |
|   |   |   \---TCP в Linux
|   |   |           Sysctl параметры: `net.ipv4.tcp_*` (syncookies, timestamps, sack, congestion control).
|   |   |           Socket buffer sizes: `rmem`, `wmem`, `rmem_max`, `wmem_max`.
|   |   |           TCP tuning: оптимизация для high-latency сетей, больших окон.
|   |   |           ss и netstat: анализ TCP-соединений, состояний (ESTABLISHED, TIME_WAIT, CLOSE_WAIT).
