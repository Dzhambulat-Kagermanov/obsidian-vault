|   |   |   +---SCTP (Stream Control Transmission Protocol)
|   |   |   |       Концепция: объединение преимуществ TCP и UDP.
|   |   |   |       Multi-homing: поддержка нескольких IP-адресов на одном соединении.
|   |   |   |       Multi-streaming: несколько независимых потоков в одном ассоциация.
|   |   |   |       Message-oriented: сохранение границ сообщений (в отличие от TCP).
|   |   |   |       Four-way handshake: защита от SYN flood атак.
|   |   |   |       Применение: SIGTRAN (телефония), Diameter (AAA), WebRTC (data channels).
|   |   |   |       Поддержка в Linux: модуль ядра `sctp`, socket API.
|   |   |   |
|   |   |   +---DCCP (Datagram Congestion Control Protocol)
|   |   |   |       Концепция: ненадежная доставка с контролем перегрузок.
|   |   |   |       Применение: streaming, VoIP (устаревший, редко используется).
|   |   |   |       RFC 4340: спецификация протокола.
|   |   |   |
|   |   |   \---QUIC (Quick UDP Internet Connections)
|   |   |           Концепция: TCP-like надежность поверх UDP.
|   |   |           Преимущества: 0-RTT и 1-RTT установка соединения, встроенное шифрование (TLS 1.3).
|   |   |           Multiplexing: несколько потоков без head-of-line blocking.
|   |   |           Connection migration: смена IP/порта без разрыва соединения.
|   |   |           Применение: HTTP/3 (основа), gRPC over QUIC.
|   |   |           Реализации: Google QUIC, IETF QUIC (RFC 9000).
