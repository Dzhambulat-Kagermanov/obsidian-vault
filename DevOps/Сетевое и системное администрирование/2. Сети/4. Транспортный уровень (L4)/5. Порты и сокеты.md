|   |   |   +---Порты (Ports)
|   |   |   |       Концепция: 16-битный идентификатор (0-65535).
|   |   |   |       Диапазоны: Well-Known (0-1023), Registered (1024-49151), Dynamic/Private (49152-65535).
|   |   |   |       Назначение: мультиплексирование приложений на одном хосте.
|   |   |   |       Привилегированные порты: требуют root-прав (Linux: <1024).
|   |   |   |       Ephemeral ports: временные порты для клиентских соединений.
|   |   |   |       Port exhaustion: проблема нехватки портов, решения (tcp_tw_reuse, увеличение диапазона).
|   |   |   |       Список портов: `/etc/services`, IANA registry.
|   |   |   |
|   |   |   +---Сокеты (Sockets)
|   |   |   |       Концепция: абстракция для сетевого взаимодействия (Berkeley Sockets API).
|   |   |   |       Типы сокетов: `SOCK_STREAM` (TCP), `SOCK_DGRAM` (UDP), `SOCK_RAW` (сырые).
|   |   |   |       Socket API: `socket()`, `bind()`, `listen()`, `accept()`, `connect()`, `send()`, `recv()`, `close()`.
|   |   |   |       Socket options: `setsockopt()`, `getsockopt()` (SO_REUSEADDR, SO_KEEPALIVE, TCP_NODELAY).
|   |   |   |       Blocking vs Non-blocking sockets: режимы работы.
|   |   |   |       I/O Multiplexing: `select()`, `poll()`, `epoll()` (Linux), `kqueue()` (BSD).
|   |   |   |       Async I/O: `io_uring` (современный Linux), AIO.
|   |   |   |
|   |   |   \---Практическое использование
|   |   |           netcat (nc): тестирование портов, передача данных.
|   |   |           socat: продвинутый инструмент для работы с сокетами.
|   |   |           ss и netstat: просмотр сокетов и соединений.
|   |   |           lsof: поиск процессов, использующих конкретные порты.
