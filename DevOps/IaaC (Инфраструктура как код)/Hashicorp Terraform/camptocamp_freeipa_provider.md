
Провайдер `camptocamp/freeipa` для Terraform предназначен для **автоматизации управления ресурсами FreeIPA** с использованием инфраструктуры как кода (IaC). Он позволяет администраторам описывать состояние объектов FreeIPA в конфигурационных файлах Terraform и автоматически применять их, вместо ручного создания через веб-интерфейс (WebUI) или командную строку (CLI)

**Основные функции и возможности провайдера:**

- **Автоматизация DNS:** Управление DNS-записями (A, AAAA, CNAME, SRV и др.) внутри FreeIPA.
- **Управление пользователями и группами:** Автоматическое создание, обновление и удаление пользователей и групп.
- **Управление хостами:** Регистрация и настройка клиентских узлов.
- **Интеграция с CI/CD:** Позволяет включать настройки FreeIPA в пайплайны развертывания инфраструктуры.

### Настройка подключения:

```hcl
terraform {
  required_providers {
    freeipa = {
      source  = "camptocamp/freeipa"
      version = "~> 0.8.0" # последняя стабильная ветка
    }
  }
}

provider "freeipa" {
  url          = "https://ipa.example.com"
  username     = "admin"
  password     = var.ipa_password
  ca_cert_path = "/path/to/ipa-ca.crt"
  # insecure = false # по умолчанию false
  # otp        = null # опционально: TOTP токен
}
```

| Параметр         | Тип      | Обязательный | По умолчанию | Описание                                                                                |
| ---------------- | -------- | ------------ | ------------ | --------------------------------------------------------------------------------------- |
| `host`           | `string` | ✅            | -            | Хост для подключения к FreeIPA                                                          |
| `username`       | `string` | ✅            | -            | Учётная запись с правами на управление объектами (обычно `admin` или сервисный аккаунт) |
| `password`       | `string` | ✅            | -            | Пароль пользователя. **Чувствителен**, автоматически помечается как `sensitive` в state |
| `insecure`       | `bool`   | ❌            | `false`      | Отключает проверку TLS-сертификата. **Не рекомендуется для production**                 |

### Основные ресурсы и их параметры:

#### freeipa_user:

Управление учётными записями пользователей.

|Параметр|Тип|Обязательный|Описание|
|---|---|---|---|
|`uid`|`string`|✅|Логин пользователя (уникальный)|
|`givenname`|`string`|✅|Имя|
|`sn`|`string`|✅|Фамилия|
|`password`|`string`|❌|Пароль. Если не указан, пользователь создаётся с флагом `--random` или требует сброса при первом входе|
|`mail`|`string`|❌|Основной email|
|`ssh_public_keys`|`list(string)`|❌|Список SSH-ключей (PEM-строки)|
|`groups`|`list(string)`|❌|Группы, в которые добавляется пользователь|
|`homedir`|`string`|❌|Путь к домашнему каталогу (по умолчанию `/home/<uid>`)|
|`shell`|`string`|❌|Оболочка (по умолчанию `/bin/sh`)|
|`uid_number`|`number`|❌|UID (если не указан, генерируется автоматически)|
|`gid_number`|`number`|❌|GID первичной группы|
|`userauthtype`|`string`|❌|Тип аутентификации: `password`, `radius`, `otp`, `pkinit`|
|`setattr`|`map(string)`|❌|Произвольные LDAP-атрибуты в формате `attr=value`|
|`force`|`bool`|❌|`true` позволяет игнорировать конфликты при удалении/изменении|
