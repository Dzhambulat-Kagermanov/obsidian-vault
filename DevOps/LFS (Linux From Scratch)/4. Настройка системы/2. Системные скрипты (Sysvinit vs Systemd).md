   |   |       LFS-Bootscripts: традиционный SysVinit подход.
|   |   |       Альтернатива: Systemd в LFS (отдельная книга BLFS).
|   |   |       Структура скриптов: `/etc/rc.d/rc.sysinit`, `/etc/rc.d/rc0.d` - `rc6.d`.
