OpenStack CLI (openstackclient)
|   |   |   |   |   |       Установка: `pip install python-openstackclient`.
|   |   |   |   |   |       Аутентификация: `openrc` файл, переменные окружения (OS_AUTH_URL, OS_USERNAME, OS_PASSWORD, OS_PROJECT_NAME).
|   |   |   |   |   |       Application Credentials: современная альтернатива паролям (`openstack application credential create`).
|   |   |   |   |   |       Формат вывода: `--format json|yaml|table|value|shell`, `--column`, `--filter`.
|   |   |   |   |   |       Batch-операции: xargs, циклы в bash, массовое управление ресурсами.

Legacy CLI (для старых версий)
|   |   |   |   |   |       `nova`, `neutron`, `cinder`, `glance`, `keystone` — устаревают, но встречаются в production.
|   |   |   |   |   |       Миграция на unified `openstack` CLI.

SDK и библиотеки
|   |   |   |   |   |       openstacksdk (Python): основной SDK для автоматизации.
|   |   |   |   |   |       gophercloud (Go): для Go-разработчиков.
|   |   |   |   |   |       Apache Libcloud: мультиоблачный SDK (OpenStack + другие).
|   |   |   |   |   |       Terraform provider (openstack): `terraform-provider-openstack`.
|   |   |   |   |   |       Ansible modules: `openstack.cloud` collection.

Horizon (Web Dashboard)
|   |   |   |   |           Структура: Project vs Admin vs Identity панели.
|   |   |   |   |           Project: инстансы, образы, keypairs, security groups, volumes, networks.
|   |   |   |   |           Admin: hypervisors, aggregates, flavors, services, quotas, метрики.
|   |   |   |   |           Кастомизация: темы, branding, скрытие панелей.
