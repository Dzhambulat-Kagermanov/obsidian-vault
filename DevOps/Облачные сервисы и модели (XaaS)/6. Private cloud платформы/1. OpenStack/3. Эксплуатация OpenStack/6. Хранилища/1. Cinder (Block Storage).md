|   |   |   |   |   |       Volumes: создание, attach/detach к инстансам.
|   |   |   |   |   |       Volume types: SSD, HDD, encrypted, different backends.
|   |   |   |   |   |       Snapshots: point-in-time копии, создание volume из snapshot.
|   |   |   |   |   |       Backups: в Swift или S3, incremental, restore.
|   |   |   |   |   |       Consistency groups: согласованные снапшоты нескольких volumes.
|   |   |   |   |   |       Backends: LVM, Ceph RBD, NFS, Pure Storage, NetApp.
|   |   |   |   |   |       Multi-attach: volume к нескольким инстансам одновременно.
