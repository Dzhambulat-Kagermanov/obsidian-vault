### Рабочие группы и домены:

Сети объединяющие клиентскую и серверную инфраструктуру под управлением операционных систем Windows делятся на два вида одноранговые и доменные. 

* Одноранговые - это сети которые основаны на рабочей группе каждый компьютер в
одноранговой сети одновременно и клиент и сервер. В таком случае например для обмена файлами по сети каждый подключается к каждому. То есть все участники являются равноправными и нет какого-либо главного компьютера такая структура подходит для небольших офисов но когда сотрудников становится больше двадцати начинаются проблемы. Число 20 здесь является ключевым поскольку таким количеством одновременных подключений к сетевым ресурсам ограничены пользовательские системы семейства Windows. 

![[Снимок экрана 2026-04-14 155658.png]]

* **Доменная сеть** - здесь есть центральный сервер или серверы, которые управляют всеми процессами в доменной сети, они раздают доступы к файлам принтерам и приложениям. Сервер - это компьютер с более мощным железом, а зачастую это вообще виртуальная машина.

### Типы ОС Windows:

* **Пользовательские** - для персональных ПК, оптимизированные для UI и пользовательских приложений, Предназначены для конечных пользователей, игр, офисной работы и мультимедиа
	- **Windows 11:** Актуальная система с современным интерфейсом.
	- **Windows 10:** Предыдущая, все еще популярная версия.
	- **Особенности:** Приоритет задачам переднего плана, удобный GUI, поддержка потребительского оборудования, отсутствие ограничений на количество одновременных пользователей.
* **Серверные** - для управления сетью, базами данных и высокими нагрузками. Серверные ОС приоритезируют фоновые процессы и многопользовательский режим. Разработаны для ИТ-инфраструктуры, обеспечения надежности и работы в режиме 24/7. Особенностью является возможность установки так называемых ролей, простыми словами это наделение сервера особыми функциями, позволяющими выполнять то ради чего он и приобретался например это может быть файловый сервер, почтовый сервер печати, веб-сервер и так далее по списку.
	* **Windows Server 2022/2025:** Современные версии с фокусом на облачную интеграцию (Azure) и безопасность.
	- **Windows Server 2019:** Стабильная версия для облачных и традиционных приложений.
	- **Другие версии:** 2003, 2008, 2008 R2, 2012, 2012 R2, 2016;
	- **Особенности:** Оптимизация под фоновые процессы, работа с большим объемом ОЗУ, встроенные роли (Active Directory, DHCP, DNS, IIS), многопользовательский режим.
	- **Редакции серверных ОС:**
		1. **Datacenter:** Для высоко виртуализированных ЦОД.
		2. **Standard:** Для физических или слабо виртуализированных сред.
		3. **Essentials:** Для малого бизнеса (до 25 пользователей).
