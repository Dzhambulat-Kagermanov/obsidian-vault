│  RENDER (React)     →  Вызов функции компонента             │
│  COMMIT (React)     →  Обновление реального DOM             │
│  PAINT (Браузер)    →  Отрисовка пикселей на экране         │
└─────────────────────────────────────────────────────────────┘

**Запомнить:**

- Render — это НЕ отрисовка. Это вычисление: «Как должен выглядеть UI?»
    
- Render может происходить, но DOM не меняться (если результат тот же)
    
- Тяжелый render блокирует paint → тормоза интерфейса
