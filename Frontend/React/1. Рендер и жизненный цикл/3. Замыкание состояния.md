Это НЕ особенность React, а особенность JavaScript!
Каждый рендер = новая локальная переменная = новые замыкания
React не может "обновить" старую функцию — только создать новую

```ts
function Component() {
  const [count, setCount] = useState(0);
  
  const handleClick = () => {
    // Эта функция "запомнила" count из РЕНДЕРА, где создалась
    console.log(count);
  };
}
```

**Решения:**

1. Функциональное обновление: `setCount(prev => prev + 1)`
    
2. useRef для "живого" значения
    
3. Правильные зависимости в useEffect/useCallback
