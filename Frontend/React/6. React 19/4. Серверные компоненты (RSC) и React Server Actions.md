**Цель:** Освоение современной парадигмы React 18/19, где граница клиент-сервер проходит внутри дерева компонентов. **Что записать:**

- **Client vs Server Components:** Правило "Server Components by default". Что можно делать только на клиенте (`useState`, `useEffect`, event listeners), а что только на сервере (прямой доступ к БД, чтение файлов).
- **Границы сериализации:** Какие данные можно передавать через пропсы от сервера к клиенту (только JSON-сериализуемые, никаких функций или экземпляров классов).
- **React Server Actions (`"use server"`):** Мутация данных напрямую из форм или обработчиков событий без создания отдельных API-роутов.
- **`useActionState` и `useFormStatus`:** Новые хуки React 19 для элегантной обработки состояний загрузки и ошибок при отправке форм.
- **Streaming и Suspense:** Показ скелетонов (`<Suspense fallback={...}>`) для медленных частей страницы, не блокируя рендеринг всего остального контента.
