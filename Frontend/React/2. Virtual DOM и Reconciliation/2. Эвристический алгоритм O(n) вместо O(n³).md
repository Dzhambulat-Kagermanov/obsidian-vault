**Допущения алгоритма:**

1. Разные типы элементов → разные деревья (удаляем всё поддерево)
    
2. Стабильные ключи → стабильные элементы
    

**Когда алгоритм сдает позиции:**

- Без ключей → все элементы пересоздаются
    
- index как key → проблема при перестановке/вставке в начало
    
- Глубоко вложенные списки → рекурсивный обход всего дерева
    
- Частые перестановки → O(n) сравнений все равно происходит
