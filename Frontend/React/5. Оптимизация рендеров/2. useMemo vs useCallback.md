```tsx
useMemo(() => value, deps)      // мемоизация значения
useCallback(() => {}, deps)      // мемоизация функции

// useCallback(fn, deps) === useMemo(() => fn, deps)
```

**Когда использовать (только при реальной проблеме):**

- Тяжелые вычисления (массив 1000+)
    
- Передача в memo-компонент
    
- Зависимость в другом хуке
    

**Когда НЕ использовать:**

- Простые операции (a + b)
    
- Передача в обычный DOM-элемент
    
- Нет измеримой проблемы
