**Цель:** Надежно тестировать сетевые запросы, не поднимая реальный бэкенд. **Что записать:**

- **Почему MSW, а не мокинг `fetch`/`axios`:** MSW перехватывает запросы на уровне Service Worker (в браузере) или Node.js (в тестах), что делает код приложения "чистым" от тестовых хаков.
- **Настройка MSW для тестов:** Инициализация `setupServer`, добавление хендлеров (`rest.get`, `http.get` для MSW v2).
- **Сценарии:**
    - Успешный ответ (Happy path).
    - Ошибка сервера (500) и обработка fallback-UI.
    - Задержка сети (`delay`) для тестирования спиннеров загрузки.
- **Интеграция с React Query / SWR:** Как правильно ждать окончания запроса в тесте.
