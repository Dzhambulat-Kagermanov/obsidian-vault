**Цель:** Автоматизировать запуск тестов при каждом Pull Request, чтобы человеческий фактор не пропускал баги. **Что записать:**

- **Базовый пайплайн (на примере GitHub Actions):** Шаги `checkout`, `setup-node`, `install`, `run tests`.
- **Оптимизация скорости:**
    - Кэширование `node_modules` и зависимостей (например, кэш Playwright браузеров).
    - Параллельный запуск (sharding) для больших наборов E2E тестов.
- **Отчетность:** Генерация отчетов в формате JUnit или Allure, интеграция с Codecov для отслеживания покрытия кода (Code Coverage).
- **Политика слияния:** Требование прохождения всех проверок (Status Checks) перед мержем в `main`.
