**Цель:** Понимание того, как Three.js взаимодействует с браузером, и настройка среды разработки. **Что записать:**

- Архитектура: Canvas API → WebGL Context → Three.js абстракции.
- Установка: `npm i three`, импорт через ES-модули (`import * as THREE from 'three'`).
- **Инструменты отладки:**
    - Three.js Editor (онлайн).
    - Расширение браузера _React Three Devtools_ (работает и для чистого Three.js).
    - _Spector.js_ (для отладки WebGL вызовов).
    - `dat.GUI` или `lil-gui` для интерактивной настройки параметров в реальном времени.
