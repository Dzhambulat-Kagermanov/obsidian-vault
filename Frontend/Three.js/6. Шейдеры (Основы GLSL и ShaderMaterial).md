**Цель:** Выход за рамки стандартных материалов для создания уникальных визуальных эффектов (вода, голограммы, искажения). **Что записать:**

- Пайплайн рендеринга: Vertex Shader (позиции) → Rasterization → Fragment Shader (пиксели).
- Типы данных в GLSL: `float`, `vec2`, `vec3`, `vec4`, `mat4`, `sampler2D`.
- Ключевые переменные: `attribute` (данные вершин, например, `position`, `uv`), `uniform` (глобальные данные, передаваемые из JS), `varying` (передача данных из вершинного во фрагментный шейдер).
- `THREE.ShaderMaterial` vs `THREE.RawShaderMaterial`.
- Практические примеры: анимированные волны на плоскости, эффект растворения (dissolve) через текстуру шума, голографический сканер.
