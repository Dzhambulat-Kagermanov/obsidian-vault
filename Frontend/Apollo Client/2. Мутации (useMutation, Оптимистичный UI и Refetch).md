**Цель:** Изменение данных на сервере и мгновенное, плавное обновление интерфейса. **Что записать:**

- **Хук `useMutation`:** Возвращает кортеж `[mutate, { data, loading, error }]`.
- **Способы обновления UI после мутации:**
    1. `refetchQueries`: Простой, но неэффективный способ (делает лишний сетевой запрос).
    2. `update` функция (Best Practice): Чтение текущего состояния кэша (`cache.readQuery`) и его модификация (`cache.writeQuery` или `cache.modify`) без сетевого запроса.
- **Оптимистичный ответ (`optimisticResponse`):** Передача ожидаемого ответа сервера _до_ того, как он придет. Apollo мгновенно обновит UI, а при реальной ошибке сети автоматически откатит изменения (rollback).
