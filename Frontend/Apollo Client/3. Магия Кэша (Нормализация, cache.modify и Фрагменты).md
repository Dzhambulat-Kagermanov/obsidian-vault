**Цель:** Глубокое понимание того, как Apollo хранит данные, и ручное управление кэшем (самый сложный и важный навык). **Что записать:**

- **Принцип нормализации:** Как Apollo превращает JSON-ответ в плоскую таблицу (граф). Роль полей `__typename` и `id` (или `_id`). Что делать, если у сущности нет `id` (настройка `keyFields` в `InMemoryCache`, например, `keyFields: ["slug"]`).
- **GraphQL Фрагменты (`fragment`):** Создание переиспользуемых кусков запросов. Использование `... on TypeName` (inline fragments) для полиморфных типов (интерфейсов и юнионов).
- **`cache.modify` (Современный стандарт):** Мощный способ обновления кэша. Удаление элемента из списка, обновление конкретного поля без переписывания всего объекта. Использование API `fields` и `readField`.
- **`cache.evict` и `cache.gc`:** Принудительное удаление сущностей из кэша (например, при логауте) и запуск сборщика мусора для освобождения памяти.
