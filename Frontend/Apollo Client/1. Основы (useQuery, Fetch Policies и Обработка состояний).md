**Цель:** Эффективное получение данных с правильным управлением кэшем. **Что записать:**

- **Хук `useQuery`:** Возвращаемые значения (`data`, `loading`, `error`, `networkStatus`, `refetch`, `fetchMore`). Разница между `loading` (первичная загрузка) и `networkStatus === 4` (refetch).
- **Fetch Policies (Критически важно!):**
    - `cache-first` (дефолт: быстро, но может быть устаревшим).
    - `cache-and-network` (идеально для дашбордов: показывает кэш мгновенно, потом тихо обновляет с сервера).
    - `network-only` (игнорирует кэш, полезно для чувствительных к актуальности данных, например, балансов).
    - `no-cache` (полностью отключает чтение и запись в кэш, полезно для одноразовых действий).
- **Переменные (Variables):** Типизация переменных запроса. Как изменение переменных автоматически создает новую запись в кэше или обновляет существующую.
- **`useLazyQuery`:** Когда использовать (поиск по вводу, открытие модалки). Отличие от `useQuery`: не выполняется при маунте, возвращает функцию-триггер.
