**Цель:** Полная типобезопасность и удобная отладка сложных графовых запросов. **Что записать:**

- **GraphQL Code Generator (`@graphql-codegen/cli`):**
    - Почему это _обязательно_ для production. Генерация TypeScript-типов (`TypedDocumentNode`) прямо из `.graphql` файлов или схемы сервера.
    - Плагин `typescript-react-apollo` для генерации готовых типизированных хуков (например, `useGetUserQuery`), что избавляет от ручного прописывания дженериков.
- **Apollo Client DevTools:** Расширение для браузера. Вкладка "Cache" (визуализация нормализованного графа, поиск по ID), "Queries" (активные запросы и их переменные), "Mutations".
- **Тестирование:** Использование `MockedProvider` из `@apollo/client/testing` для написания Unit-тестов компонентов без реального сервера (мокирование конкретных запросов и переменных).
