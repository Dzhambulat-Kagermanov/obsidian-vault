**Цель:** Эффективное получение данных на фронтенде с нужной глубиной и фильтрацией. **Что записать:**

- **REST API v5 Query Syntax:**
    - Фильтрация: `filters[title][$contains]=strapi`.
    - Сортировка и пагинация: `sort=createdAt:desc`, `pagination[page]=1&pagination[pageSize]=10`.
    - **Population (Раскрытие связей):** Критически важный параметр `populate=*` или `populate[blocks][populate]=*` для Dynamic Zones. Без него связи и компоненты придут пустыми.
- **GraphQL:** Установка плагина `@strapi/plugin-graphql`. Преимущества GraphQL для фронтенда (избегание over-fetching, особенно при сложных Dynamic Zones). Настройка кастомных резолверов.
- **Sanitization:** Почему Strapi автоматически очищает ответы от приватных полей (пароли, email) и как это работает.
