**Цель:** Использование готовых UI-элементов и обеспечение доступности. **Что записать:**

- **MiniMap:** Настройка `nodeColor`, `maskColor`, `style`. Оптимизация: отключение или упрощение MiniMap при очень больших графах (он может тормозить).
- **Controls:** Кнопки зума и фитирования. Кастомизация через пропс `controls` или создание своих кнопок с использованием хука `useReactFlow`.
- **Background:** Варианты `variant` (dots, lines, cross), цвет, размер шага (`gap`, `size`, `offset`).
- **Доступность (a11y):** Встроенная поддержка клавиатуры (стрелки для перемещения нод, Delete для удаления, Tab для навигации по handles). Настройка `aria-label` для кастомных нод.
