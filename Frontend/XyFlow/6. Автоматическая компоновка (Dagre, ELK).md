**Цель:** Автоматическое красивое расположение нод, чтобы пользователю не пришлось расставлять их вручную. **Что записать:**

- **Почему это сложно:** XYFlow не имеет встроенного auto-layout, он полагается на внешние библиотеки.
- **Интеграция с Dagre:** Использование `@dagrejs/dagre` для иерархических графов (Top-to-Bottom, Left-to-Right). Настройка `rankdir`, `nodesep`, `ranksep`.
- **Интеграция с ELK:** Использование `@xyflow/layout` (официальная обертка над Eclipse Layout Kernel) для более сложных, ортогональных и компактных схем (особенно хорошо для блок-схем и архитектурных диаграмм).
- **Паттерн применения:** Получение данных → запуск алгоритма layout → обновление позиций нод через `setNodes` → вызов `fitView`.
