**Цель:** Программное управление графом и синхронизация с внешним стейтом (Zustand/Redux). **Что записать:**

- **`useReactFlow`:** Хук для получения методов управления: `setNodes`, `setEdges`, `addNodes`, `addEdges`, `updateNodeData`, `deleteElements`, `fitView`, `zoomIn`, `zoomOut`, `screenToFlowPosition`, `flowToScreenPosition`.
- **`useStore`:** Хук для чтения _внутреннего_ состояния XYFlow без лишних ререндеров. Пример: `const selectedNode = useStore(state => state.nodes.find(n => n.selected))`. Использование селекторов обязательно!
- **Синхронизация с внешним стейтом:** Паттерн "Single Source of Truth". Хранить `nodes` и `edges` во внешнем Zustand-сторе, передавать их в XYFlow, а изменения из `onNodesChange` синхронизировать обратно через `applyNodeChanges` / `applyEdgeChanges`.
- **Undo/Redo:** Реализация истории изменений с использованием `@xyflow/react` утилит или кастомного стора, сохраняющего снапшоты графа.
