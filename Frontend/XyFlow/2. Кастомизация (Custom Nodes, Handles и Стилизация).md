**Цель:** Создание уникальных, функциональных узлов, соответствующих дизайну продукта. **Что записать:**

- **Регистрация типов:** Передача объекта `nodeTypes` в пропс `<ReactFlow>`. _Важно:_ этот объект должен быть мемоизирован (`useMemo`) или вынесен за пределы компонента, чтобы не вызывать полные перерисовки.
- **Компонент Custom Node:** Получение пропсов (`id`, `data`, `selected`, `isConnectable`). Использование `React.memo` для кастомных нод (абсолютный маст-хэв для производительности).
- **Handles (Точки соединения):** Компонент `<Handle>`. Пропсы: `type` (source/target), `position` (top, right, bottom, left), `id` (для множественных соединений на одной ноде), `isConnectable` (можно ли к нему подключаться), `isValidConnection` (кастомная валидация соединения).
- **Стилизация:** Подход к CSS (Tailwind, CSS Modules, styled-components). Использование CSS-переменных для динамических цветов на основе `data`.
