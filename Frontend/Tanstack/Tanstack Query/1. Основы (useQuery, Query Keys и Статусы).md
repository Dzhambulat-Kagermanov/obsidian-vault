**Цель:** Освоение базового хука и главного механизма кэширования. **Что записать:**

- **Query Key (Ключ запроса):** _Самая важная концепция._ Должен быть массивом (даже для одного элемента: `['users']`). Иерархия ключей: `['posts', 'list', { page: 1 }]` → `['posts', 'detail', postId]`.
- **Функция запроса (Query Function):** Должна возвращать Promise. Почему нельзя передавать инлайн-функции с замыканиями без массива зависимостей (лучше использовать замыкание или передавать параметры через объект).
- **Статусы:** `isLoading` (первый запрос, нет данных), `isFetching` (любой фоновый запрос), `isError`, `isSuccess`, `data`, `error`. Разница между `isLoading` и `isFetching` критична для UX (показывать скелетон только при `isLoading`).
- **Типизация:** `UseQueryResult<TData, TError>`, типизация промиса в query function.
