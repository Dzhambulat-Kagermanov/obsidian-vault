**Цель:** Мгновенный отклик интерфейса на действия пользователя до ответа сервера. **Что записать:**

- **`useMutation`:** Хук для создания, обновления, удаления данных. `onSuccess`, `onError`, `onSettled`.
- **Паттерн Оптимистичного обновления (Пошагово):**
    1. `onMutate`: Отменить исходящие запросы (`cancelQueries`), сделать снапшот предыдущих данных (`getQueryData`), обновить кэш на клиенте (`setQueryData`) на ожидаемое значение.
    2. `onError`: Если сервер вернул ошибку, откатить кэш к снапшоту из `onMutate`.
    3. `onSettled`: Всегда инвалидировать запрос (`invalidateQueries`), чтобы синхронизировать кэш с реальным состоянием сервера, даже если оптимистичное обновление "угадало".
- **Контекст мутации:** Передача данных из `onMutate` в `onError`/`onSettled` через `return` в `onMutate`.
