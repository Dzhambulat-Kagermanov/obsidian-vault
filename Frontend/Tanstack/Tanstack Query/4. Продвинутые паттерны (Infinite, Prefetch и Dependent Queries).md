**Цель:** Решение сложных сценариев взаимодействия с данными. **Что записать:**

- **`useInfiniteQuery`:** Для бесконечного скролла (Infinite Scroll). Ключевые параметры: `getNextPageParam`, `getPreviousPageParam`, структура `data.pages` и `data.pageParams`. Метод `fetchNextPage` и флаг `isFetchingNextPage`.
- **Зависимые запросы (Dependent Queries):** Запрос, который выполняется только при наличии данных из другого запроса. Реализуется через передачу `enabled: !!userId` или `queryKey: ['posts', userId]` (если `userId` null, запрос не выполняется).
- **Prefetching (Предвыборка):** `queryClient.prefetchQuery` при наведении мыши (`onMouseEnter`) на ссылку или кнопку, чтобы данные уже были в кэше к моменту клика.
- **`useQueries`:** Выполнение массива независимых запросов параллельно (например, загрузка данных для списка ID, когда нельзя использовать один запрос с `WHERE IN`).
