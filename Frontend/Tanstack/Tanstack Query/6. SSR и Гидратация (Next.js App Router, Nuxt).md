**Цель:** Правильная передача данных с сервера на клиент без лишних запросов (Waterfall). **Что записать:**

- **Next.js App Router:** Использование `dehydrate` и `HydrationBoundary` из `@tanstack/react-query`.
- **Паттерн:**
    1. В Server Component: создать `QueryClient`, сделать `await queryClient.prefetchQuery(...)`.
    2. Передать `dehydrate(queryClient)` в Client Component через пропсы.
    3. В Client Component: обернуть контент в `<HydrationBoundary state={dehydratedState}>`.
- **Почему это важно:** Позволяет использовать `useQuery` на клиенте, но данные уже будут там, и запрос на сервер не пойдет.
- **Streaming:** Как TanStack Query работает с React Suspense на сервере (частичная гидратация).
