**Цель:** Поддержание чистоты кода и высокой скорости работы приложения. **Что записать:**

- **TanStack Query DevTools:** Обязательный инструмент. Как читать вкладки "Queries" (статусы, время последнего фетча, размер кэша) и "Mutations".
- **Структурирование API-слоя:** Вынос функций запроса в отдельные файлы (`api/getPosts.ts`), а не написание их прямо внутри `useQuery`. Это позволяет переиспользовать их в `prefetchQuery` или Server Actions.
- **Антипаттерны:**
    - Хранение данных из `useQuery` в `useState` или `useEffect` (нарушает single source of truth).
    - Слишком короткие `staleTime` для редко меняющихся данных (справочники, настройки).
    - Использование `any` для типов данных запроса.
- **Тестирование:** Использование `QueryClientProvider` с `defaultOptions: { queries: { retry: false } }` в тестах, чтобы они не зависали при ошибках. Мокинг через `vi.mock` или MSW.
