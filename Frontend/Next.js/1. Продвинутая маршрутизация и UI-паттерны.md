**Цель:** Использование всех возможностей роутера для создания сложного, но чистого UX. **Что записать:**

- **Специальные файлы:** `layout.tsx` (сохраняет состояние при навигации), `page.tsx`, `loading.tsx` (автоматический Suspense), `error.tsx` (Error Boundary), `not-found.tsx`.
- **Параллельные маршруты (Parallel Routes):** Синтаксис `@folder` для независимого рендеринга частей страницы (например, сайдбар и основной контент обновляются независимо).
- **Перехватывающие маршруты (Intercepting Routes):** Синтаксис `(..)folder` для открытия модалок поверх текущего контента с сохранением URL-контекста (идеально для галерей или быстрых действий).
- **Middleware:** Выполнение кода на Edge до завершения запроса. Использование для редиректов, A/B тестов или базовой проверки токенов.
