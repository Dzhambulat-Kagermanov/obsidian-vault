**Цель:** Построение защищенной системы входа, учитывающей специфику RSC. **Что записать:**

- **Auth.js (NextAuth v5) vs Supabase Auth:** Плюсы и минусы. Интеграция Supabase Auth Helpers для Next.js (готовые хуки и middleware).
- **Защита маршрутов:**
    - На уровне сервера: проверка сессии в `layout.tsx` или `page.tsx` с редиректом (`redirect('/login')`).
    - На уровне Middleware: быстрая проверка JWT для защиты целых групп роутов (`/dashboard/*`).
- **Row Level Security (RLS) в Supabase:** Настройка политик в БД, чтобы пользователь мог читать/писать только свои данные. Как передавать JWT из Next.js в Supabase для применения RLS на сервере.
- **Безопасность Server Actions:** Валидация входных данных с помощью **Zod** перед любой работой с БД (никогда не доверять данным с клиента).
