**Цель:** Обеспечение надежности и наблюдаемости приложения в продакшене. **Что записать:**

- **Тестирование:**
    - Unit: Vitest для утилит и Server Actions (мокинг БД).
    - E2E: Playwright для проверки полных пользовательских сценариев (включая авторизацию).
- **Мониторинг:** Подключение Vercel Analytics, Vercel Speed Insights и Vercel Logs для отслеживания Real User Monitoring (RUM) метрик и ошибок сервера.
- **Переменные окружения:** Валидация `.env` файлов на этапе сборки с помощью библиотек типа `@t3-oss/env-nextjs` или `zod`, чтобы приложение падало при сборке, если не хватает критичных ключей, а не в рантайме.
