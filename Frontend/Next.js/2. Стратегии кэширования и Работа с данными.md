**Цель:** Управление 4 уровнями кэша в Next.js, чтобы приложение было мгновенным, но данные оставались актуальными. **Что записать:**

- **Уровни кэширования:**
    1. Request Memoization (дедупликация одинаковых `fetch` в одном рендер-цикле).
    2. Data Cache (сохранение результата `fetch` на сервере между запросами пользователей).
    3. Full Route Cache (сохранение HTML/RSC payload при сборке или первом рендере).
    4. Router Cache (кэш на стороне клиента в браузере).
- **Управление `fetch`:** Опции `next: { revalidate: 60 }` (ISR) и `next: { tags: ['products'] }`.
- **Инвалидация кэша:** Функции `revalidatePath('/dashboard')` и `revalidateTag('products')` внутри Server Actions.
- **`unstable_cache`:** Кэширование результатов тяжелых вычислений или запросов к сторонним API, не использующих `fetch`.
