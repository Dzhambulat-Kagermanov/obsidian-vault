**Цель:** Замена традиционных API Routes (`/api/...`) на типобезопасные серверные функции. **Что записать:**

- **Синтаксис:** Директива `"use server"` в отдельном файле или внутри компонента.
- **Интеграция с формами:** Атрибут `action` в `<form>`. Обработка ошибок и редиректов (`redirect()`) прямо из серверной функции.
- **Хуки React 19 для мутаций:**
    - `useActionState` (бывший `useFormState`): управление состоянием загрузки, ошибками и результатом действия формы.
    - `useFormStatus`: получение статуса (`pending`) отправки формы из дочерних компонентов (например, для блокировки кнопки Submit).
- **Оптимистичные обновления:** Хук `useOptimistic` для мгновенного отображения изменений в UI до завершения серверного запроса (например, добавление лайка или сообщения в чат).
