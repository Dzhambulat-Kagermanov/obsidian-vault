**Цель:** Использование лучших инструментов для ускорения разработки. **Что записать:**

- **VueUse:** "Lodash для Composition API". Топ полезных композируемых функций: `useLocalStorage`, `onClickOutside`, `useWindowSize`, `useIntersectionObserver`, `useDebounceFn`.
- **Vite:** Базовая настройка `vite.config.ts` для Vue (плагины `@vitejs/plugin-vue`, алиасы путей `@/`).
- **Vue DevTools (v7+):** Как инспектировать реактивность, отслеживать срабатывание событий, редактировать стейт Pinia в реальном времени, вкладка Timeline.
