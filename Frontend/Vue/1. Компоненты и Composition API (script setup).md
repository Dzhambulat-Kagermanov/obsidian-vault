**Цель:** Освоение основного синтаксиса, который ты будешь писать 95% времени. **Что записать:**

- **Макросы компилятора:** `defineProps`, `defineEmits`, `defineExpose`, `defineOptions`.
- **Двустороннее связывание:** Эволюция от `.sync` к `v-model:propName` и новый макрос **`defineModel()`** (стандарт с Vue 3.4+, кардинально упрощающий создание кастомных инпутов).
- **Слоты (Slots):** Дефолтные, именованные (`<template #header>`) и **scoped slots** (передача данных из дочернего компонента в слот родителя).
- **Динамические компоненты:** `<component :is="CurrentComponent">` и паттерн для переключения табов/виджетов.
- **Шаблонные ссылки (Template Refs):** Привязка `ref` к DOM-элементу или дочернему компоненту (с учетом `onMounted`).
