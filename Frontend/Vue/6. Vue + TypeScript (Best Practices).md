**Цель:** Полная типизация Vue-приложений без использования `any`. **Что записать:**

- Типизация пропсов: `defineProps<{ title: string; count?: number }>()` и использование `withDefaults` для значений по умолчанию.
- Типизация эммитов: `defineEmits<{ (e: 'update:modelValue', value: string): void }>()`.
- Типизация refs: `const input = ref<HTMLInputElement | null>(null)`.
- **Generic-компоненты:** Как создать переиспользуемый компонент (например, таблицу или селект), который принимает тип данных через пропс (использование `<script setup lang="ts" generic="T">` в Vue 3.3+).
- Типизация ответов от API и сторов Pinia.
