**Цель:** Глобальное управление состоянием (Vuex официально устарел, Pinia — стандарт). **Что записать:**

- **Setup Stores vs Option Stores:** Почему Setup Stores (`defineStore('id', () => { ... })`) предпочтительнее (полная поддержка TS, возможность использовать композируемые функции внутри стора).
- **State, Getters, Actions:** Паттерны изменения состояния (прямая мутация в Pinia в отличие от Vuex).
- **Плагины:** `pinia-plugin-persistedstate` для сохранения стора в `localStorage`/`sessionStorage` из коробки.
- **Взаимодействие с компонентами:** Использование стора внутри `<script setup>` через `const store = useMyStore()`.
