**Цель:** Понимание того, как Vue работает под капотом, чтобы избегать магического поведения и багов. **Что записать:**

- **Reactivity System:** Как работает `Proxy` во Vue 3 (отличие от `Object.defineProperty` во Vue 2). Ограничения реактивности (например, деструктуризация реактивных объектов без `toRefs`).
- **Жизненный цикл (Lifecycle):** Маппинг хуков: `beforeCreate`/`created` → `setup()`, `mounted` → `onMounted`, `beforeUnmount` → `onBeforeUnmount`.
- **SFC (Single File Component):** Анатомия `.vue` файла (`<template>`, `<script setup>`, `<style scoped>`).
- **Директивы:** `v-if` vs `v-show` (когда что использовать), `v-for` (и почему всегда нужен `key`, и почему `key` не должен быть `index` массива при изменении порядка).
