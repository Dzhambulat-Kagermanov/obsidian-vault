**Цель:** Надежное покрытие компонентов и логики. **Что записать:**

- **Vitest:** Настройка в паре с Vite (быстрый запуск, совместимость API с Jest).
- **Vue Test Utils (VTU):** Разница между `mount` (полный рендер) и `shallowMount` (заглушка дочерних компонентов).
- **Паттерны тестирования:**
    - Тестирование рендера (наличие текста/элементов).
    - Тестирование взаимодействия (`await wrapper.find('button').trigger('click')`).
    - Мокинг Pinia (`createTestingPinia`) и Vue Router (`createMockRouter`).
    - Тестирование композируемых функций (composables) в изоляции.
