**Цель:** Построение навигации в SPA-приложениях. **Что записать:**

- **Конфигурация:** Создание роутера, `createWebHistory` vs `createWebHashHistory`.
- **Composition API в роутере:** Хуки `useRoute()` (для чтения параметров) и `useRouter()` (для программной навигации `router.push`).
- **Навигационные хуки (Guards):** `beforeEach` (для проверки авторизации), `beforeEnter` (на уровне роута), `onBeforeRouteLeave` (для предупреждения о несохраненных данных).
- **Оптимизация:** Lazy loading роутов (`component: () => import('./View.vue')`) для разделения кода (code splitting).
- **Scroll Behavior:** Настройка прокрутки при переходе между страницами или использовании хэшей (`#section`).
