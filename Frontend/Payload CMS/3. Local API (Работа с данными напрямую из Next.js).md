**Цель:** Использование главного преимущества Payload — выполнение запросов к БД без сетевых издержек и с соблюдением прав доступа. **Что записать:**

- **Получение экземпляра:** `const payload = await getPayload()` внутри Server Component или Server Action.
- **CRUD операции:** `payload.find()`, `payload.findByID()`, `payload.create()`, `payload.update()`, `payload.delete()`.
- **Параметры запросов:** `where` (сложные условия: `equals`, `contains`, `like`, `and`/`or`), `limit`, `page`, `sort`, `depth` (глубина раскрытия отношений, по умолчанию 0 для производительности).
- **Override Access:** Использование `{ overrideAccess: true }` (только внутри доверенного серверного кода, например, в cron-задачах или админских скриптах).
