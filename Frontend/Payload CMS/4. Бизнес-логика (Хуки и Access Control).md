**Цель:** Внедрение кастомной логики и строгих правил безопасности на уровне базы данных. **Что записать:**

- **Хуки коллекций:** `beforeValidate`, `beforeChange` (модификация данных перед сохранением, например, генерация slug), `afterChange` (отправка email, очистка кэша), `afterRead`.
- **Хуки полей:** Аналогично, но применяются к конкретному полю (например, автоматический расчет значения).
- **Access Control (Критически важно!):**
    - Функции `access: { read, create, update, delete, admin }`.
    - Пример: `read: ({ req: { user } }) => Boolean(user)` (только авторизованные).
    - Доступ на уровне полей (`admin: { readOnly: ({ req }) => !req.user }`).
- **Кастомные эндпоинты:** Создание своих REST-рутов внутри Payload для специфичных задач, не укладывающихся в стандартный CRUD.
