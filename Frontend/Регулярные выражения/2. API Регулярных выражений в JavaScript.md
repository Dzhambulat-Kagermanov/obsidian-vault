**Цель:** Знать, какой метод JS-объектов `String` или `RegExp` использовать для конкретной задачи. **Что записать:**

- **Создание:** Литерал `/pattern/flags` (компилируется один раз, рекомендуется) vs конструктор `new RegExp('pattern', 'flags')` (когда паттерн динамический).
- **Флаги:** `g` (глобальный поиск), `i` (игнорирование регистра), `m` (многострочный), `s` (dotAll, чтобы `.` захватывал переносы строк), `y` (sticky, поиск только с текущей позиции), `d` (indices, получение начального и конечного индексов совпадения).
- **Методы RegExp:**
    - `regex.test(str)` — самый быстрый способ проверить наличие (возвращает boolean).
    - `regex.exec(str)` — для получения детальной информации о совпадении (особенно с флагом `g` в цикле).
- **Методы String:**
    - `str.match(regex)` / `str.matchAll(regex)` (возвращает итератор, идеально для множественных совпадений с группами).
    - `str.replace(regex, replacement)` — использование функций в replacement для сложной логики (например, `str.replace(/\$(\w+)/g, (match, p1) => data[p1])`).
    - `str.split(regex)` — разделение по сложным разделителям.
