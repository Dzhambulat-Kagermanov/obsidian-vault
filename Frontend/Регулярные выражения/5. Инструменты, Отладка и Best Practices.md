**Цель:** Научиться быстро писать, проверять и поддерживать читаемость regex. **Что записать:**

- **Онлайн-тестеры:** Regex101.com (выбор диалекта ECMAScript, пошаговое объяснение, библиотека паттернов), RegExr.
- **Читаемость в коде:**
    - Вынос сложных regex в именованные константы с понятными именами (`const EMAIL_REGEX = /.../`).
    - Использование комментариев. Поскольку в JS нет флага `/x` (свободные пробелы и комментарии внутри regex), показывать паттерн создания regex через конструктор с объединением строк или использование современных трюков (например, тегированные шаблонные строки).
- **VS Code:** Встроенный поиск по regex (`Alt+R`), полезные расширения для подсветки синтаксиса regex в строках.
- **Главное правило:** Если регулярное выражение занимает больше 2-3 строк и его нельзя объяснить коллеге за 10 секунд, возможно, задачу лучше решить через комбинацию методов `split`, `slice`, `includes` или парсер (например, для сложного HTML лучше использовать DOM API, а не regex).
