**Цель:** Бесшовное встраивание императивного Canvas в декларативные фреймворки. **Что записать:**

- **Жизненный цикл:** Инициализация `Application` в `useEffect` / `onMounted`. _Обязательная_ очистка в `return () => { app.destroy(true, { children: true, texture: true }) }`.
- **Рефы:** Хранение экземпляра `app` и корневых контейнеров в `useRef` / `ref`, а не в стейте (чтобы избежать лишних ререндеров React/Vue).
- **Адаптивность (Resize):** Правильный обработчик `window.resize`: обновление `renderer.resize(width, height)`, обновление `app.stage.scale` для сохранения пропорций (например, паттерн "letterbox" или "cover").
- **Слои (Z-Index):** Паттерн наложения DOM-элементов (HTML UI, кнопки, модалки) поверх Canvas с помощью `position: absolute` и `pointer-events: none` / `auto`.
