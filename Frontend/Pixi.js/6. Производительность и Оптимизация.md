**Цель:** Достижение стабильных 60/120 FPS. Это самый важный файл в разделе. **Что записать:**

- **Draw Calls (Вызовы отрисовки):** Главная метрика. Как работает Texture Batching (группировка спрайтов с одинаковой текстурой в один вызов). Использование Texture Atlas (спрайтовых листов) для минимизации draw calls.
- **Object Pooling (Пул объектов):** _Запрет_ на создание `new Sprite()` или `new Graphics()` внутри игрового цикла или при частых событиях. Паттерн: создать массив объектов заранее, активировать/деактивировать их по мере необходимости.
- **Очистка (Cleanup):** Полный гайд по уничтожению: остановка тикеров, уничтожение ассетов, отписка от событий, вызов `destroy()` с правильными флагами.
- **Избегание Layout Thrashing:** Не менять размер `canvas.style.width` каждый кадр. Использовать внутреннее масштабирование Pixi.
