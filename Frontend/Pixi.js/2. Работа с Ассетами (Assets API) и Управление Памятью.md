**Цель:** Эффективная загрузка, кэширование и, что важнее, _уничтожение_ ресурсов. **Что записать:**

- **Assets API:** `Assets.load()`, `Assets.add()`, `Assets.loadBundle()`. Почему это лучше старого `Loader`.
- **Фоновая загрузка:** Использование `Assets.backgroundLoad()` для предзагрузки тяжелых ассетов, пока пользователь взаимодействует с первым экраном.
- **Кэширование и CORS:** Настройка `crossOrigin` для загрузки изображений с других доменов (необходимо для применения фильтров и извлечения пикселей).
- **Уничтожение (Garbage Collection):** Правило №1 в Pixi: `sprite.destroy({ children: true, texture: true, baseTexture: true })`. Почему простого удаления из `container` недостаточно (утечка видеопамяти GPU).
