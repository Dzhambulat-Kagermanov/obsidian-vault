**Цель:** Быстрое нахождение узких мест и визуальных багов. **Что записать:**

- **PixiJS DevTools:** Расширение для браузера (аналог React DevTools) для инспекции дисплей-листа в реальном времени.
- **Встроенная отладка:** `app.renderer.extract.image()` или `.canvas()` для сохранения текущего кадра и проверки артефактов рендеринга.
- **Мониторинг FPS:** Использование `stats.js` или кастомного счетчика на базе `app.ticker` для отображения FPS и количества Draw Calls прямо на экране.
- **Texture Garbage Collection:** Настройка `PIXI.settings.GC_MAX_IDLE` и `GC_MAX_CHECK_COUNT` для управления тем, как часто Pixi очищает неиспользуемые текстуры из памяти GPU.
