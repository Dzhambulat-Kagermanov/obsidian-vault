**Цель:** Понять, почему GSAP, а не CSS-анимации, и выучить базовый синтаксис. **Что записать:**

- **GSAP vs CSS Animations:** Преимущества GSAP (высокая производительность, полный контроль через JS, кроссбраузерность, возможность паузы/реверса).
- **Подключение:** CDN, npm (`npm install gsap`), важность `gsap.registerPlugin()`.
- **Селекторы:** Как GSAP работает со строками (`".box"`), массивами DOM-элементов и рефами (`useRef`).
