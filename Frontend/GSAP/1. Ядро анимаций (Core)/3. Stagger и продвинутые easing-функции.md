**Цель:** Делать анимации «живыми» и органичными, а не механическими. **Что записать:**

- **Stagger:** Анимация массива элементов с задержкой. Простой `stagger: 0.1` vs продвинутый объект `stagger: { amount: 1, from: "center", grid: "auto", ease: "power1.inOut" }`.
- **Easing:** Встроенные функции (`power1.inOut`, `elastic`, `bounce`, `back`).
- **CustomEase:** Как использовать кастомные кривые Безье (и ссылка на визуальный редактор GreenSock).
