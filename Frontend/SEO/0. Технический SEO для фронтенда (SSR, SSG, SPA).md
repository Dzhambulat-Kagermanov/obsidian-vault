**Цель:** Понимание того, как архитектура приложения влияет на возможность поисковых роботов проиндексировать контент. **Что записать:**

- **Проблема SPA:** Почему чистый React/Vue (Client-Side Rendering) плохо индексируется (пустой HTML при первом запросе, зависимость от рендеринга JS).
- **Решения:**
    - SSR (Server-Side Rendering): Next.js (`getServerSideProps` / App Router), Nuxt.
    - SSG (Static Site Generation): генерация HTML на этапе сборки.
    - DSR (Dynamic Server Rendering) и гибридные подходы.
- **Файлы управления роботами:** `robots.txt` (директивы `Allow`, `Disallow`, `Sitemap`), `sitemap.xml` (динамическая генерация для больших каталогов).
- **Канонические ссылки:** `<link rel="canonical">` для борьбы с дубликатами контента (например, при пагинации или UTM-метках).
- **Обработка ошибок:** Правильные HTTP-статусы (404, 500) и их отдача даже в SPA (через серверные заголовки или мета-тег `robots` с `noindex`).
