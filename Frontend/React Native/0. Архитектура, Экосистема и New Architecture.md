**Цель:** Понимание того, как RN работает под капотом, и выбор правильного инструментария. **Что записать:**

- **Expo vs React Native CLI:** Почему в 95% случаев сейчас выбирают Expo (Expo Go, Dev Client, Prebuild). Когда _необходим_ чистый CLI.
- **Потоки выполнения (Threading model):** JS Thread (логика), UI Thread (нативный рендеринг), Shadow Thread (расчет Layout через Yoga).
- **New Architecture (Fabric, TurboModules, JSI):** Как она работает, почему убирает асинхронный "мост" (Bridge), как включить её в проекте и какие дает преимущества (синхронное выполнение, ленивая загрузка).
- **Движок Hermes:** Почему он включен по умолчанию, как он ускоряет запуск приложения (bytecode) и экономит память.
