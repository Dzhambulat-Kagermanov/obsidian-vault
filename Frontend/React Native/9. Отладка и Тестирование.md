**Цель:** Быстрое нахождение багов, специфичных для мобильных платформ. **Что записать:**

- **Отладка:** React Native Debugger, Flipper (и его преемники), логи устройства (`adb logcat` для Android, Console.app для iOS).
- **Отладка UI:** Inspect Element в Expo Go, React DevTools.
- **Unit-тесты:** Jest + React Native Testing Library (мокинг нативных модулей через `jest.mock`).
- **E2E-тесты:** Почему Cypress не подходит. Использование **Maestro** (современный, простой YAML-синтаксис, кроссплатформенный) или **Detox** (серый ящик, стабильность, но сложнее в настройке).
