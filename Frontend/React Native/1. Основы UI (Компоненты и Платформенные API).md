**Цель:** Изучение базовых строительных блоков, отличных от веб-версии React. **Что записать:**

- **Core Components:** `View`, `Text`, `Image`, `ScrollView`, `FlatList`, `TextInput`, `SafeAreaView`, `KeyboardAvoidingView`.
- **Платформенные компоненты:** `Platform.OS`, `Platform.select`, `Pressable` (вместо устаревшего `TouchableOpacity`), `Switch`, `Modal`.
- **Работа с клавиатурой:** `Keyboard` API, `KeyboardAvoidingView` (настройка `behavior="padding"` для iOS и `height` для Android), скрытие клавиатуры по тапу вне поля.
- **Обработка жестов на базовом уровне:** `PanResponder` (и почему сейчас лучше использовать `react-native-gesture-handler`).
