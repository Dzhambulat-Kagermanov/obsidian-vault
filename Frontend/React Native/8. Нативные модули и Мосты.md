**Цель:** Понимание того, как писать или подключать код на Swift/Kotlin, когда возможностей JS недостаточно. **Что записать:**

- **Старый подход (Bridge):** `RCT_EXPORT_MODULE`, асинхронная передача JSON-сообщений (и почему это медленно).
- **Новый подход (JSI - JavaScript Interface):** Прямой синхронный вызов C++ функций из JS.
- **Expo Modules API:** Современный, типобезопасный способ написания нативных модулей (поддерживает и Expo, и bare RN).
- **Поиск готовых решений:** Как читать документацию нативных библиотек, проверка на поддержку New Architecture и последней версии RN.
