**Цель:** Построение сложной, типизированной и плавной навигации, так как в мобильном приложении нет URL и истории браузера. **Что записать:**

- **Типы навигаторов:** `Stack` (основной), `Tabs` (нижнее меню), `Drawer` (боковое меню), `Native Stack` (использует нативные `UINavigationController` / `Fragment` для лучшей производительности).
- **Передача параметров:** Типизация пропсов экранов (`NativeStackScreenProps`), передача и чтение `params`.
- **Вложенная навигация (Nested Navigators):** Как правильно организовать структуру (например, Tabs внутри Stack).
- **Глубокие ссылки (Deep Linking):** Настройка `linking` в конфиге, обработка универсальных ссылок (Universal Links для iOS, App Links для Android).
- **Жизненный цикл экрана:** События `focus`, `blur`, `beforeRemove` (для предотвращения случайного закрытия с несохраненными данными).
