**Цель:** Создание плавных, нативных анимаций, работающих на UI-потоке, а не на JS-потоке. **Что записать:**

- **React Native Reanimated (v3+):** Концепция Worklets (`'worklet'` директива). Почему анимации должны выполняться на UI Thread.
- **Хуки Reanimated:** `useSharedValue`, `useAnimatedStyle`, `useDerivedValue`, `withSpring`, `withTiming`.
- **React Native Gesture Handler:** Обработка свайпов, панорамирования, тапов. Интеграция с Reanimated (`useAnimatedGestureHandler`).
- **Layout Animations:** Использование `LayoutAnimation` (для простых перестроений) или `Reanimated Layout Transitions` (для сложных переходов при изменении DOM-дерева).
- **Связка с навигацией:** Кастомные переходы между экранами через `react-navigation-shared-element` или кастомные анимации стека.
